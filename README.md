📘 Python3 – From Basics to Advanced (with Flask & SQLite)

A comprehensive learning repository by Abdiaziz Haredh

🌍 Overview

This repository is a complete, structured Python learning journey designed for beginners, students, and anyone looking to strengthen their Python and backend development skills.

It covers the full progression—from Python fundamentals, to Object-Oriented Programming (OOP), to advanced concepts, and finally into Flask, SQLite, and database-driven applications.

I created this repo while mentoring and guiding learners, and it now serves as a practical reference for both new developers and those refining their backend engineering skills.

🎯 Learning Goals

By working through this repository, you will learn how to:

Understand Python basics and core programming concepts

Apply control flow, loops, functions, and modules

Build real applications using OOP principles

Work with decorators, properties, class methods, and advanced Python tools

Create and manage SQLite databases

Build full backend apps using Flask

Understand ORM, migrations, and data modeling

Structure clean, maintainable code following best practices

1. Clone the repository

cd python3

2. Install dependencies

pipenv install
pipenv shell

3. Run a Flask application
python app.py
